# Student Task Management System

A simple web app to add, search and manage student tasks. Built as a pair assignment to practice Git and GitHub in a real collaborative workflow.

## Project Description

Student Task Manager lets a student add study tasks with a title and a description, see them as task cards, and search them by keyword. The project was built by two students using feature branches, GitHub Issues, Pull Requests, code reviews, merge conflict resolution, a version tag and a GitHub Release.

## Features

- Add tasks using a form with a title and a description
- Show tasks as styled task cards
- Search tasks by keyword (not case-sensitive)
- Responsive, styled layout for small screens

- HTML5

## Git Workflow

1. Create a feature branch from `main`
2. Make changes and commit with a meaningful message
3. Push the branch to GitHub
4. Open a Pull Request that describes the change and how it was tested
5. The other student reviews, comments and approves
6. Merge into `main`
7. Pull the updated `main` locally and repeat

Features were linked to GitHub Issues with `Closes #1` in the Pull Request description.

## Branches

| Branch | Purpose |
|---|---|
| `main` | Stable code, only updated through Pull Requests |
| `feature/task-form` | Task input form (M Ayan Rauf) |
| `feature/task-style` | Layout, buttons, task cards, responsive design (Adeel Luqman) |
| `feature/task-search` | Task search, closes issue #1 (Adeel Luqman) |
| `docs/readme-b` | `index.html` title change by Adeel Saeed (merge conflict demo) |

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/muhammadayanrauf/student-task-manager.git
   ```
2. Open the `student-task-manager` folder
3. Open `index.html` in any web browser
4. Add a task using the form, then type in the search box to filter tasks
