# Student Task Manager

## Project Description
A simple web application that lets users add, display, complete, delete, and search tasks. Built by a two-person team to demonstrate a collaborative Git and GitHub workflow.

## Features
- Add tasks with a title and description
- Display tasks as cards
- Mark tasks as completed
- Delete tasks
- Search tasks
- Responsive layout

## Technologies
- HTML5, CSS3, JavaScript
- Git and GitHub

## Git Workflow
Feature branch workflow: each feature was developed on its own branch, pushed to GitHub, reviewed through a Pull Request, and merged into `main`. Features were tracked with GitHub Issues.

## Branches
- `main`: stable code
- `feature/task-form`: task input form
- `feature/task-style`: styling and responsive design
- `feature/task-search`: task search

## Git Commands Demonstrated
`git init`, `git status`, `git add`, `git commit`, `git log`, `git branch`, `git switch`, `git diff`, `git diff --staged`, `git clone`, `git remote`, `git push`, `git fetch`, `git pull`, `git merge`, `git stash`, `git restore`, `git reset`, `git revert`, `git show`, `git blame`, `git tag`

## GitHub Features Demonstrated
Repository, Issues, Pull Requests, Code Reviews, Merging, Issue linking (`Closes #n`), Tags, Releases, Contributors

## How to Run
1. Clone the repository:
   ```
   git clone https://github.com/muhammadayanrauf/student-task-manager.git
   ```
2. Open the folder `student-task-manager`.
3. Open `index.html` in any web browser.
